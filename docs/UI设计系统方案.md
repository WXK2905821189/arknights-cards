# 罗德岛棋局 · UI 设计系统方案（v1）

> 适用对象：`arknights-cards` 自走棋 web 版（延续现有项目）
> 平台：桌面 Web ｜ 风格：暗色科幻 / 方舟美术 ｜ 目标：美观且好用，贴合已有用户习惯
> 设计者：UI Designer

---

## 0. 设计目标与基调

在**现有暗色科幻调性**上做「收口与升级」，而不是推翻重做——你已经养成的用户习惯（拖拽上场、费色识别、HP/金币资源条、全屏战斗演出）全部保留，只解决一致性、可读性与可达性问题。

现状盘点（已读 `game.html` / `game.css` / `index.html` / `style.css`）：

| 已做好的（保留） | 待修正的（本方案解决） |
| --- | --- |
| 深空蓝黑底 + 罗德岛金主色，调性统一 | 两套 CSS token 命名漂移：`--ink`/`--text`、`--gold`/`--gold2`、`--bg`/`--bg2` 并存 |
| 费色语言一致：白1/绿2/蓝3/紫4/金5 | `.card-tags` 被定义两次、布局互相矛盾 |
| 方舟风单位卡（头像满铺 + 底栏渐变 + 费色边框） | 缺少统一的动效时长/缓动规范 |
| 进度流程条、羁绊面板、全屏战斗演出结构清晰 | 焦点态/键盘可达性未系统化（无障碍缺口） |
| 图鉴页带搜索/筛选/缩放详情，体验完整 | 主对局内羁绊「左侧面板 + 顶部条」信息重复 |

---

## 1. 设计原则（5 条）

1. **暗色为骨，金为魂**——深空蓝黑是唯一底色，金色是唯一品牌主色，其余皆语义色，避免多色抢戏。
2. **靠明度分层**——用「背景明度 + 金线 + 间距」三级建立层次，而不是堆边框和阴影。
3. **费色语言全局唯一**——白1/绿2/蓝3/紫4/金5 是全场景唯一费用编码（卡面边框、费用点、图例一致）。
4. **操作可预期**——默认 / 悬停 / 选中 / 拖拽 / 禁用 五态完备，反馈即时（≤200ms）。
5. **键盘可达 & 尊重敏感**——所有交互可键盘完成，并尊重 `prefers-reduced-motion`。

---

## 2. 颜色系统（统一 Token）

合并两套 CSS 的命名，定下**一套语义变量为准**，写入共享的 `tokens.css`，`game.css` 与 `style.css` 都引用它，消除漂移。

```css
:root{
  /* —— 基础 surface（靠明度建立层级） —— */
  --bg:        #0e1116;   /* 页面底 */
  --bg-sunk:   #0a0d12;   /* 凹陷区：棋盘、日志 */
  --panel:     #171c24;   /* 面板 */
  --panel-2:   #1f2630;   /* 次级面板 / 卡面 */
  --line:      #2c3543;   /* 描边 / 分隔 */
  --line-soft: #222a35;

  /* —— 文本 —— */
  --text:      #e7ecf3;   /* 主文（对比度 14.6:1 ✅） */
  --text-2:    #9aa7b8;   /* 次要文（对比度 6.1:1 ✅） */
  --text-3:    #6b7787;   /* 禁用 / 极弱 */

  /* —— 品牌金（唯一主色） —— */
  --gold:      #e8b84b;
  --gold-strong:#f4d27a;
  --gold-deep: #cf9a2e;
  --gold-soft: rgba(232,184,75,.12);

  /* —— 语义色 —— */
  --ally:   #5ac8e0;  /* 我方 */
  --enemy:  #e07a5a;  /* 敌方 */
  --hp:     #e05a5a;  /* 生命 */
  --success:#5fd08a;
  --warning:#f5c542;
  --danger: #e05a5a;
  --info:   #5aa0e0;

  /* —— 职业色（8） —— */
  --c-vanguard:#6fcf97; --c-guard:#eb5757; --c-defender:#56a0e0;
  --c-sniper:#f2c94c;  --c-caster:#bb6bd9; --c-medic:#5ac8e0;
  --c-supporter:#4dc9b0; --c-specialist:#f2994a;

  /* —— 费色（全局唯一编码） —— */
  --cost-1:#c8ccd2; --cost-2:#22c55e; --cost-3:#3b82f6;
  --cost-4:#a855f7; --cost-5:#e8b84b;
}
```

**对比度核对**：`--text` 在 `--bg` 上 14.6:1，`--text-2` 6.1:1，金色按钮文字（深底 `#1a1408`）对比达标——均满足 WCAG AA（正文 4.5:1 / 大字 3:1）。

## 3. 字体与排版

- 字体栈：`"PingFang SC","Microsoft YaHei","Segoe UI",system-ui,sans-serif`
- 字号阶梯（桌面）：12 / 13 / 14 / 16 / 18 / 20 / 24 / 30 / 36（px）
- 字重：400 常规 / 600 半粗 / 700 粗（按钮、标题）
- 行高：正文 1.6、紧凑列表 1.5、标题 1.2
- **数字一律 `font-variant-numeric: tabular-nums`**（金币 / 经验 / HP / 费用），对齐稳定、读数不跳。

---

## 4. 间距与栅格

- 基数 4px；阶梯 `4 / 8 / 12 / 16 / 24 / 32 / 48 / 64`
- 桌面容器 `max-width: 1100px`（主对局）与 `1280px`（图鉴/宽屏）
- 面板内边距 12–16px，区块间距 12px，主区块 14–18px

---

## 5. 层级、圆角、阴影

- 圆角：芯片/徽章 999px（全圆）；按钮 8px；卡面 10–14px；面板 12px
- 阴影三档：`--sh-1` 卡面静止、`--sh-2` 悬停上浮、`--sh-3` 弹窗/选中聚焦
- 分层靠 **surface 明度 + 1px `--line` 描边**，阴影仅用于「浮起反馈」，不滥用

---

## 6. 动效规范

```css
--ease: cubic-bezier(.2,.7,.3,1);
--dur-fast: 120ms;   /* 悬停/边框变色 */
--dur:      200ms;   /* 上浮/位移 */
--dur-slow: 300ms;   /* 弹窗/大区块 */
```

- 所有 `transition` 引用上述时长，杜绝「有的 0.08s、有的 0.5s」的杂乱。
- 全局包裹 `@media (prefers-reduced-motion: reduce){ * { transition:none !important; animation:none !important } }`。

## 7. 组件库（规格 + 状态）

### 7.1 按钮 `.btn`
变体：`primary`（金底深字）/ `ghost`（描边）/ `danger`（红边）。
五态：default → hover（上浮 1px + 金边）/ active（下沉）/ **focus-visible（2px 金环 offset 2，键盘可见）** / disabled（opacity .4，禁指针）。
尺寸：`default` 14px/9×16，`small` 12px/6×10。

### 7.2 单位卡 `.ucard`（棋盘/备战席）& `.shop-card`（商店）
- 费色边框 2px（c1–c5）；头像满铺 `object-fit:cover`；底部 62% 渐变遮罩保证文字可读
- 标签区：职业/阵营/签名 三色小标签（已有，本方案统一 `.card-tags` 为**单列左对齐**一处定义）
- 底栏：名字（左，单行省略）+ 费用金币（右，发光）
- 五态：默认 → hover（上浮 3px + 金边 + `--sh-2`）→ 选中（金环 2px）→ dragging（opacity .25）→ sold/locked（灰/半透）
- 星级角标（左上，金）

### 7.3 面板 / 弹窗 `.overlay` + `.panel`
- 遮罩 `rgba(8,10,14,.86)` + 可选 `backdrop-filter: blur`
- 面板圆角 12、内边距 26×30、最大宽按内容（策略卡 640、技能 520、羁绊 680）
- 关闭按钮右上圆形，键盘 `Esc` 可关

### 7.4 羁绊组件（统一为「羁绊条」）
- **取消**左侧面板与顶部条的重复呈现，统一为一个可折叠「羁绊条」：已激活金色左线 + ✦，未激活灰，悬停展开详情
- 条目：左侧 3px 状态线 + 圆点（on=金）+ 名称 + 当前/所需档位

### 7.5 进度流程条 `.node-flow`
- 保留现有「节点 + 连线」结构，规范化：done（✓、半透）/ current（金边 + 脉冲）/ upcoming（正常）
- 顶部固定、横向滚动，桌面不换行

### 7.6 战斗单位 `.bf-unit`
- 我方青框 / 敌方赭框；头像 + 名 + 血条（青/赭）+ 技条（金）
- 状态：casting（金闪 ✦）/ has-shield（青环）/ dead（灰 + 半透）
- 站位用 `transform` 平滑移动（`.3s linear`）

### 7.7 徽章 / 费用点 / 输入
- chip/徽章：全圆、职业色底深字或描边变体
- 费用点 `.cost-dot`：圆形饱和色 + 深色数字，全场景一致
- 搜索/下拉（图鉴）：聚焦金边 + 柔光环

## 8. 关键界面布局（桌面 Web）

```
┌ 顶栏：品牌「罗德岛棋局 // 货币战争」│ 资源(💰/Lv/❤/节点/难度/连胜) │ 🔊 │ ← 图鉴 ┐
├ 进度流程条 node-flow（可选，对局内）                                          │
├ 主对局 arena ──────────────────────────────────────────────────────────────┤
│  ┌ 羁绊条(可折叠) ┐ │ 敌情预览 → 我方部署区(3×3) → 备战席 → 商店(5卡) → 行动条 │
├ 战斗：全屏演出（战场 grid 在上，战斗日志在下，跳过按钮右上）                    │
├ 结算 / 策略节点 / 遭遇节点：overlay 卡片选择                                    │
└ 图鉴 index.html：网格(自动填充) + 筛选/搜索 + 立绘详情弹窗(可缩放)             ┘
```

- 主对局采用「左窄栏(羁绊) + 中主区」弹性布局；`<860px` 时窄栏堆叠到顶部（已有响应式规则，保留）。
- 单位操作条 `.unit-bar`：选中单位后底部居中浮出（头像/属性/羁绊/技能/售出），保留。

## 9. 无障碍（WCAG AA）

- **焦点可见**：所有可交互元素 `:focus-visible` 显示 2px 金/青环，offset 2px。
- **对比度**：正文 ≥ 4.5:1，大字 ≥ 3:1（见 §2 核对）。
- **键盘可达拖拽**：保留鼠标拖拽，**新增「点击选中 → 点击目标格」备选上场路径**，照顾无法拖拽 / 触屏用户。
- **语义与标签**：图标按钮加 `aria-label`（音效、刷新、跳过）；面板加 `role="dialog"` + `aria-modal`。
- **动效敏感**：尊重 `prefers-reduced-motion`，关闭非必要动画。
- **触控下限**：桌面以鼠标为主，但交互元素最小高度 ≥ 32px，移动断点下 ≥ 44px。

## 10. 开发落地建议

1. **抽离 `tokens.css`**：把 §2 的统一变量放独立文件，在 `game.css` / `style.css` 顶部 `@import` 或 `<link>`，删除 `--ink`/`--text` 等重复命名，全项目只认一套语义名。
2. **清理重复**：删除 `game.css` 中第二处 `.card-tags` 定义（现 §320 与 §80 冲突），统一为单列左对齐。
3. **统一动效**：把散落的 `.08s/.12s/.5s` 替换为 §6 的 `--dur*` 变量。
4. **羁绊收敛**：合并左侧面板与顶部条为单一「羁绊条」组件，减少信息重复与维护成本。
5. **键盘上场**：在现有拖拽逻辑旁补一条 `click` 选中→`click` 落格路径（`game.js` 加 ~20 行）。
6. **预览即规范**：本目录 `design-preview.html` 是这套系统的可交互样板，开发对照实现即可保证一致性。

> 设计完成度目标：界面元素一致性 ≥ 95%，无障碍达 WCAG AA，开发返工率 < 10%。
